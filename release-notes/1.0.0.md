## What's new in 1.0.0

- **Beyond Meter.** The meter has a new name and its own releases. It is a fork of
  [AION2 DPS Meter](https://github.com/cyberbadger6969/aion2-dps-meter) by cyberbadger6969, free software under the
  GPL-3.0 licence.
- **Installs over AION2 DPS Meter.** The installer replaces the original meter and keeps its settings, fight history
  and boss timers. The old shortcuts and program file are removed.
- **Updates come from Beyond Meter.** The update check now looks at this project's releases only.
- **Linux overlay.** A native overlay for AION 2 under Steam/Proton: damage and healing views, fight breakdown,
  history, boss respawn timers, recording and replay of the game traffic, chat lines and class icons. Unpack the
  tarball and run `install.sh`.

## Installing on Windows

Run `BeyondMeter-Setup.exe`. If Windows says *"Windows protected your PC"*, click *More info* → *Run anyway*: the
installer is not signed. Installing the original AION2 DPS Meter again later replaces Beyond Meter.
